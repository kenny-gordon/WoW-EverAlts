# EverAlts

EverAlts is a World of Warcraft addon for tracking currencies, gold, inventory, professions, and known recipes across your characters.

## Features

- View each character or an account-wide summary.
- Track currencies, bag inventory, bank inventory while the bank is open, and gold.
- Browse professions and learned recipes; item tooltips show characters that hold or can craft an item.
- Open the window from the minimap button or with `/everalts` or `/ea`.
- Use `/ea minimap` to toggle the minimap button and `/ea delete Name-Realm` to remove saved character data.

## Installation

Copy the `EverAlts` folder into your World of Warcraft client's `Interface/AddOns` directory, then restart the game or run `/reload`.

## Upgrading from Alterego

EverAlts continues using the existing `AlteregoDB` saved variable and supports `/alterego` and `/ae` as command aliases, so your saved character data and existing commands remain available.
